# tyovi-veri

Herkese açık piyasa verisi toplayıcısı (GitHub Actions, 10 dakikada bir). Çıktılar `veri` dalında:
`opsiyon.json` (opsiyon özeti, canlı gamma tablosu) ve `piyasa.json` (takvim, ETF akışı, haber başlıkları, Kalshi, VIX, Hyperliquid).

Yalnız açık kaynaklardan piyasa verisi içerir; kişisel veri yoktur. Okuma/özet amaçlıdır, yatırım tavsiyesi değildir.
